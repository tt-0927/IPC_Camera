NET_TV_VIDEO_ENCODE_OPTION_S

视频编码参数选项 Video encode option

struct
{
INT32 nId;
INT32 enVideoType;
NET_TV_VIDEO_RESOLUTION_S stVideoResolution;
INT32 enBitrateType;
INT32 enImageQuality;
INT32 enFrameRate;
INT32 nBitrateUpperLimit;
INT32 nAverageBitrate;
INT32 enVideoCodec;
BOOL bSmartEnable;
INT32 enEncodingComplexity;
INT32 nIFrameInterval;
INT32 enSvcEnable;
INT32 nBitrateSmoothing;
BYTE byRes[256];
};

Parameters

[in] nId

视频码流ID 0-主码流 1-子码流 2-JPEG

[in] enVideoType

视频类型 0-复合流 1-视频流

[in] stVideoResolution

视频分辨率

[in] enBitrateType

码率类型

[in] enImageQuality

图像质量

[in] enFrameRate

视频帧率fps

[in] nBitrateUpperLimit

码率上限kbps

[in] nAverageBitrate

平均码率kbps

[in] enVideoCodec

视频编码 NET_TV_VIDEO_CODE_TYPE_E

[in] bSmartEnable

智能编码

[in] enEncodingComplexity

编码复杂度

[in] nIFrameInterval

I帧间隔

[in] enSvcEnable

SVC智能编码

[in] nBitrateSmoothing

码流平滑

[in] byRes

保留字段，当前转换或业务实现未使用
