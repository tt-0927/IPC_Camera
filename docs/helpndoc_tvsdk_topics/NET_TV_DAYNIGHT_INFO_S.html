NET_TV_DAYNIGHT_INFO_S

日夜切换信息结构体

struct
{
INT32 enDayNightMode;
INT32 nBeginHour;
INT32 nBeginMinute;
INT32 nBeginSecond;
INT32 nBeginMilliSec;
INT32 nEndHour;
INT32 nEndMinute;
INT32 nEndSecond;
INT32 nEndMilliSec;
UINT32 nSensitivityLevel;
UINT32 nFilterTime;
BOOL bFillLightExp;
INT32 enLightMode;
INT32 enLightType;
BOOL bWhiteLightEnable;
INT32 nWhiteLightLevel;
BOOL bRedLightEnable;
INT32 nRedLightLevel;
BYTE byRes[64];
};

Parameters

[in] enDayNightMode

日夜切换模式，对应ISP::DayNightMode_E

[in] nBeginHour

日夜定时切换开始时间的小时

[in] nBeginMinute

日夜定时切换开始时间的分钟

[in] nBeginSecond

日夜定时切换开始时间的秒

[in] nBeginMilliSec

日夜定时切换开始时间的毫秒

[in] nEndHour

日夜定时切换结束时间的小时

[in] nEndMinute

日夜定时切换结束时间的分钟

[in] nEndSecond

日夜定时切换结束时间的秒

[in] nEndMilliSec

日夜定时切换结束时间的毫秒

[in] nSensitivityLevel

日夜自动切换灵敏度

[in] nFilterTime

日夜切换过滤时间

[in] bFillLightExp

补光灯曝光联动使能开关

[in] enLightMode

补光亮度模式，对应ISP::LightBrightMode_E

[in] enLightType

补光灯类型，对应ISP::LightType_E

[in] bWhiteLightEnable

白光灯使能开关

[in] nWhiteLightLevel

白光灯亮度等级

[in] bRedLightEnable

红外灯使能开关

[in] nRedLightLevel

红外灯亮度等级

[in] byRes

保留字段，当前转换或业务实现未使用

See Also

无。
