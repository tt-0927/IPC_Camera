NET_TV_RECORD_INFO_S

手动录像控制信息

struct
{
INT32 nChnId;
INT32 nVideoStatus;
INT32 nAudioStatus;
INT32 nRecordStatus;
INT32 nRecordFormat;
INT32 nEventType;
CHAR szPath[NET_TV_MAX_URL_LEN];
CHAR szRedunPath[NET_TV_MAX_URL_LEN];
CHAR szRecordName[NET_TV_FILE_NAME_LEN];
CHAR szRecordTime[NET_TV_LEN_64];
INT32 nStreamType;
BYTE byRes[128];
};

Parameters

[in] nChnId

录像控制通道号

[in] nVideoStatus

视频录像开关状态

[in] nAudioStatus

音频录像开关状态

[in] nRecordStatus

录像状态，对应NET_TV_RECORD_STATUS_E

[in] nRecordFormat

录像文件格式

[in] nEventType

事件录像关联的事件类型

[in] szPath

录像保存路径

[in] szRedunPath

冗余录像保存路径

[in] szRecordName

录像文件名

[in] szRecordTime

录像时间字符串

[in] nStreamType

录像使用的码流类型

[in] byRes

保留字段，当前转换或业务实现未使用

See Also

无。
