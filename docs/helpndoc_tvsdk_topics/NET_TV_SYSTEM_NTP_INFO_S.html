NET_TV_SYSTEM_NTP_INFO_S

系统时间/NTP校时配置，对应IPC侧System::TimeInfo_S

struct
{
INT32 enTimeZone;
INT32 enDateFormat;
BOOL bEnableNTPSync;
BOOL bManualSync;
CHAR szDateTime[NET_TV_MAX_DATE_STRING_LEN];
BOOL bIsSyncWithComputer;
CHAR szAddress[NET_TV_LEN_128];
INT32 nPort;
INT32 nSyncInterval;
BYTE byRes[128];
};

Parameters

[in] enTimeZone

时区，取值对应IPC侧System::TimeZone_E

[in] enDateFormat

日期格式，取值对应IPC侧System::DateFormat_E

[in] bEnableNTPSync

是否开启NTP校时

[in] bManualSync

是否手动校时

[in] szDateTime

手动校时时间，格式按enDateFormat解析

[in] bIsSyncWithComputer

是否与计算机时间同步

[in] szAddress

NTP服务器地址

[in] nPort

NTP服务器端口

[in] nSyncInterval

NTP同步间隔，单位分钟

[in] byRes

保留字段，当前转换或业务实现未使用

See Also

无。
