NET_TV_DISCOVERY_DEVICE_INFO_S

设备发现响应信息

struct
{
CHAR szDeviceName[NET_TV_LEN_64];
CHAR szDeviceID[NET_TV_LEN_64];
CHAR szDeviceType[NET_TV_LEN_32];
CHAR szIPv4Address[NET_TV_IPADDR_STR_MAX_LEN];
CHAR szIPv4SubnetMask[NET_TV_IPADDR_STR_MAX_LEN];
CHAR szIPv4Gateway[NET_TV_IPADDR_STR_MAX_LEN];
CHAR szMACAddress[NET_TV_LEN_32];
CHAR szFirmwareVersion[NET_TV_LEN_64];
UINT32 dwHttpPort;
CHAR szManufacturer[NET_TV_LEN_32];
BYTE byRes[128];
};

Parameters

[in] szDeviceName

设备发现响应中的设备名称，IPC侧取System::DeviceInfo_S::deviceName

[in] szDeviceID

设备发现响应中的设备ID，IPC侧优先使用序列号，缺省使用设备ID

[in] szDeviceType

设备类型字符串，IPC缺省填IPC

[in] szIPv4Address

设备发现网卡的IPv4地址

[in] szIPv4SubnetMask

设备发现网卡的IPv4子网掩码

[in] szIPv4Gateway

设备发现网卡的IPv4网关

[in] szMACAddress

设备发现网卡的MAC地址

[in] szFirmwareVersion

固件版本，IPC侧优先系统版本，缺省使用硬件版本

[in] dwHttpPort

设备HTTP服务端口，发现响应使用该端口

[in] szManufacturer

厂商名称，IPC缺省填ITC

[in] byRes

保留字段，当前转换或业务实现未使用

See Also

无。
