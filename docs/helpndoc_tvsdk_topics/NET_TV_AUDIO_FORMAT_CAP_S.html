NET_TV_AUDIO_FORMAT_CAP_S

音频格式能力集

struct
{
INT32 dwFormat;
INT32 dwSampleRateSize;
INT32 adwSampleRate[NET_TV_AUDIO_SAMPRATE_MAX];
INT32 dwBitRateSize;
INT32 adwBitRate[NET_TV_AUDIO_BITRATE_MAX];
NET_TV_AUDIO_RANGE_S stSampleRateRange;
NET_TV_AUDIO_RANGE_S stBitRateRange;
};

Parameters

[in] dwFormat

音频格式 参见 NET_TV_AUDIO_FORMAT_E

[in] dwSampleRateSize

采样率数量

[in] adwSampleRate

采样率列表 参见 NET_TV_AUDIO_SAMPRATE_E

[in] dwBitRateSize

码率数量

[in] adwBitRate

码率列表 参见 NET_TV_AUDIO_BITRATE_E

[in] stSampleRateRange

采样率范围（预留）

[in] stBitRateRange

码率范围（预留）
