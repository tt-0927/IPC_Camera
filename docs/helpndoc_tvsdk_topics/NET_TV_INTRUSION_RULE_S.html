NET_TV_INTRUSION_RULE_S

入侵检测区域规则参数

struct
{
BOOL bEnable;
INT32 dwPointCount;
FLOAT afPointX[32];
FLOAT afPointY[32];
INT32 nTimeThreshold;
INT32 nSensitivity;
INT32 dwDetectionTargetCount;
INT32 adwDetectionTarget[8];
BYTE byRes[64];
};

Parameters

[in] bEnable

是否启用

[in] dwPointCount

区域顶点数量，最多32个

[in] afPointX

区域顶点X坐标数组 [0.0-1.0]

[in] afPointY

区域顶点Y坐标数组 [0.0-1.0]

[in] nTimeThreshold

行为事件触发时间阈值，判断有效报警的时间[0,100] 单位秒

[in] nSensitivity

灵敏度[1,100]

[in] dwDetectionTargetCount

检测目标数量

[in] adwDetectionTarget

检测目标数组 NET_TV_DETECTION_TARGET_E，最多8个

[in] byRes

保留字段，当前转换或业务实现未使用

See Also

无。
