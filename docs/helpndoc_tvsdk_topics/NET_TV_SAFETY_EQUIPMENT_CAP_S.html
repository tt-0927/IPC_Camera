NET_TV_SAFETY_EQUIPMENT_CAP_S

穿戴规范检测能力

struct
{
BOOL bSupport;
BOOL bSupportHelmet;
BOOL bSupportReflectiveClothing;
BOOL bSupportSeatbelt;
BOOL bSupportRegion;
UINT32 udwMaxRegions;
UINT32 udwMaxPointsPerRegion;
NET_TV_RANGE_S stSensitivity;
BOOL bSupportColorDetect;
BYTE byRes[64];
};

Parameters

[in] bSupport

是否支持穿戴规范检测

[in] bSupportHelmet

是否支持安全帽检测

[in] bSupportReflectiveClothing

是否支持反光衣检测

[in] bSupportSeatbelt

是否支持高空安全带检测

[in] bSupportRegion

是否支持区域设置

[in] udwMaxRegions

最大区域数

[in] udwMaxPointsPerRegion

每个区域最大顶点数

[in] stSensitivity

灵敏度范围

[in] bSupportColorDetect

是否支持颜色检测

[in] byRes

保留字段，当前转换或业务实现未使用
