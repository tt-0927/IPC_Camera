NET_TV_CAPTURE_CONFIG_S

抓图配置

struct
{
BOOL bEnable;
INT32 enPictureFormat;
INT32 nWidth;
INT32 nHeight;
INT32 enImageQuality;
UINT32 unInterval;
INT32 enTimeUnit;
UINT32 unNumber;
BYTE byRes[64];
};

Parameters

[in] bEnable

抓图配置使能开关

[in] enPictureFormat

抓图图片格式，对应NET_TV_CAPTURE_PICTURE_FORMAT_E

[in] nWidth

抓图图片宽度

[in] nHeight

抓图图片高度

[in] enImageQuality

抓图图片质量，对应NET_TV_CAPTURE_IMAGE_QUALITY_E

[in] unInterval

抓图间隔数值

[in] enTimeUnit

抓图间隔时间单位，对应NET_TV_CAPTURE_TIME_UNIT_E

[in] unNumber

单次触发抓图张数

[in] byRes

保留字段，当前转换或业务实现未使用

See Also

无。
