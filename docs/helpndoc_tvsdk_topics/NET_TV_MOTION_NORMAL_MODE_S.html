NET_TV_MOTION_NORMAL_MODE_S

移动侦测普通模式参数

struct
{
INT32 nSensitivity;
INT32 nRegionType;
INT32 nRectLeft;
INT32 nRectTop;
INT32 nRectRight;
INT32 nRectBottom;
INT32 dwGridWidth;
INT32 dwGridHeight;
BYTE abyGridArea[18][22];
BYTE byRes[128];
};

Parameters

[in] nSensitivity

灵敏度 [0,100]

[in] nRegionType

区域类型 0：筒型 1：网格

[in] nRectLeft

筒型区域左坐标 (当nRegionType=0时有效)

[in] nRectTop

筒型区域上坐标

[in] nRectRight

筒型区域右坐标

[in] nRectBottom

筒型区域下坐标

[in] dwGridWidth

网格宽度 (当nRegionType=1时有效，通常22)

[in] dwGridHeight

网格高度 (当nRegionType=1时有效，通常18)

[in] BYTE abyGridArea[18][22]

网格区域标记，1表示移动侦测区域 (18x22)

[in] byRes

保留字段，当前转换或业务实现未使用

See Also

无。
