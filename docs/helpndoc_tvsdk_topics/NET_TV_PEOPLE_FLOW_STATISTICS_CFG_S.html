NET_TV_PEOPLE_FLOW_STATISTICS_CFG_S

人流统计配置信息

struct
{
BOOL bEnable;
INT32 nSensitivity;
NET_TV_PEOPLE_FLOW_RULE_LINE_S stRuleLine;
INT32 dwPointCount;
FLOAT afPointX[32];
FLOAT afPointY[32];
INT32 nReportInterval;
INT32 enStatisticsType;
NET_TV_STATISTICS_RESET_CONFIG_S stTimedReset;
NET_TV_PEOPLE_ALARM_CONFIG_S stStayAlarm;
NET_TV_ALARM_SCHEDULE_S stAlarmSchedule;
BYTE byRes[256];
};

Parameters

[in] bEnable

是否启用人流统计

[in] nSensitivity

灵敏度[1-100]

[in] stRuleLine

规则线

[in] dwPointCount

检测区域顶点数，最多32个

[in] afPointX

检测区域X坐标数组 [0.0-1.0]

[in] afPointY

检测区域Y坐标数组 [0.0-1.0]

[in] nReportInterval

数据上报间隔(秒)

[in] enStatisticsType

统计类型 NET_TV_PEOPLE_FLOW_STAT_TYPE_E

[in] stTimedReset

定时清零

[in] stStayAlarm

滞留人数报警

[in] stAlarmSchedule

布防时间

[in] byRes

保留字段，当前转换或业务实现未使用
