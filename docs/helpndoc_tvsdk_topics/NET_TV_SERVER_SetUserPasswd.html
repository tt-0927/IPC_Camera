NET_TV_SERVER_SetUserPasswd

设置SDK服务端鉴权用户名和密码

BOOL NET_TV_SERVER_SetUserPasswd(IN CHAR szUserName[NET_TV_LEN_132], IN CHAR szPassword[NET_TV_LEN_132]);

Parameters

[in] szUserName

SDK服务端鉴权用户名

[in] szPassword

SDK服务端鉴权密码

Return Values

BOOL 类型返回值。TRUE 表示成功，FALSE 表示失败。接口返回失败时可调用 NET_TV_GetLastError 获取错误码。

Remarks
