NET_TV_RECORD_FIND_RESULT_S

录像查找结果项

struct
{
INT32 nChnId;
INT32 nDateCount;
CHAR aszDates[NET_TV_RECORD_DATE_MAX_NUM][NET_TV_LEN_64];
CHAR szFilename[NET_TV_FILE_NAME_LEN];
INT32 nVideoTimeCount;
NET_TV_RECORD_VIDEO_TIME_S astVideoTimes[NET_TV_TIME_DURATION_NUM];
BYTE byRes[128];
};

Parameters

[in] nChnId

录像结果所属通道号

[in] nDateCount

返回日期数量，最多NET_TV_RECORD_DATE_MAX_NUM个

[in] CHAR aszDates[NET_TV_RECORD_DATE_MAX_NUM][NET_TV_LEN_64]

有录像的日期数组

[in] szFilename

录像文件名

[in] nVideoTimeCount

录像时间段数量，最多NET_TV_TIME_DURATION_NUM个

[in] astVideoTimes

录像时间段数组

[in] byRes

保留字段，当前转换或业务实现未使用
