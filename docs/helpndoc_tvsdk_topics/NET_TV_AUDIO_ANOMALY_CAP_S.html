NET_TV_AUDIO_ANOMALY_CAP_S

音频异常检测能力

struct
{
BOOL bSupport;
BOOL bSupportInputAnomaly;

[in] bSupportFall

[in] stRiseSensitivity

突升灵敏度范围 Rise

[in] stRiseThreshold

突升阈值范围 Rise threshold range

[in] stFallSensitivity

突降灵敏度范围 Fall

[in] byRes
