NET_TV_4G_INFO_S

4G配置

struct
{
CHAR szApn[NET_TV_LEN_64];
CHAR szUserName[NET_TV_LEN_132];
CHAR szPassword[NET_TV_LEN_132];
CHAR szCallNumber[NET_TV_LEN_32];
INT32 nMtu;
INT32 nAuthMode;
INT32 nNetworkMode;
INT32 nDialMode;
BYTE byRes[128];
};

Parameters

[in] szApn

4G拨号APN

[in] szUserName

4G拨号用户名

[in] szPassword

4G拨号密码

[in] szCallNumber

4G拨号号码

[in] nMtu

4G网络MTU

[in] nAuthMode

4G认证方式，0表示无认证，1表示PAP，2表示CHAP，3表示PAP&CHAP

[in] nNetworkMode

4G网络模式，0表示自动，1表示4G，2表示3G，3表示2G

[in] nDialMode

4G拨号模式，0表示自动，1表示手动

[in] byRes

保留字段，当前转换或业务实现未使用

无。
