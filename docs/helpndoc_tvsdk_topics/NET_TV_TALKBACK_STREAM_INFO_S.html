NET_TV_TALKBACK_STREAM_INFO_S

对讲流信息结构体

struct
{
CHAR szHost[NET_TV_LEN_64];
INT32 nPort;
INT32 nChnId;
INT32 nUserID;
BOOL bMainStream;
CHAR szProtocol[NET_TV_LEN_32];
CHAR szStartTime[NET_TV_LEN_64];
CHAR szEndTime[NET_TV_LEN_64];
CHAR szFileName[NET_TV_LEN_260];
BYTE byRes[128];
};

Parameters

[in] szHost

对讲服务器主机地址/IP

[in] nPort

对讲服务端口号

[in] nChnId

通道 ID，对应对讲通道

[in] nUserID

用户 ID，标识操作会话

[in] bMainStream

主码流标记 (true/false)

[in] szProtocol

传输协议类型 (如 rtp/raw 等)

[in] szStartTime

对讲开始时间戳

[in] szEndTime

对讲结束时间戳

[in] szFileName

对讲音频文件名/路径

[in] byRes

保留字段，未使用

See Also

无。
