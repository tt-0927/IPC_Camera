NET_TV_REPLAY_RECORD_LIST_S

NVR回放录像时间段查询结果

struct
{
INT32 dwChannel;
BOOL bFilterByEventType;
INT32 dwEventType;
CHAR szDate[NET_TV_LEN_32];
CHAR szStartTime[NET_TV_MAX_DATE_STRING_LEN];
CHAR szEndTime[NET_TV_MAX_DATE_STRING_LEN];
INT32 nVideoCount;
NET_TV_REPLAY_RECORD_TIME_S astVideoTimes[NET_TV_REPLAY_RECORD_SEGMENT_MAX];
INT32 nPersonEventCount;
NET_TV_REPLAY_RECORD_TIME_S astPersonEventTimes[NET_TV_REPLAY_RECORD_SEGMENT_MAX];
INT32 nVehicleEventCount;
NET_TV_REPLAY_RECORD_TIME_S astVehicleEventTimes[NET_TV_REPLAY_RECORD_SEGMENT_MAX];
INT32 nOtherEventCount;
NET_TV_REPLAY_RECORD_TIME_S astOtherEventTimes[NET_TV_REPLAY_RECORD_SEGMENT_MAX];
BYTE byRes[64];
};

Parameters

[in] dwChannel

通道号

[in] bFilterByEventType

是否按事件类型过滤 FALSE:不过滤 TRUE:按 dwEventType 过滤

[in] dwEventType

事件类型，取值可对齐 NVR 事件类型定义；兼容旧请求时忽略

[in] szDate

日期 "YYYY-MM-DD"

[in] szStartTime

开始时间 "YYYY-MM-DD HH:MM:SS"，为空则按整天开始

[in] szEndTime

结束时间 "YYYY-MM-DD HH:MM:SS"，为空则按整天结束

[in] nVideoCount

普通录像时间段数量

[in] astVideoTimes

普通录像回放时间段数组

[in] nPersonEventCount

人员事件时间段数量

[in] astPersonEventTimes

人员事件回放时间段数组

[in] nVehicleEventCount

车辆事件时间段数量

[in] astVehicleEventTimes

车辆事件回放时间段数组

[in] nOtherEventCount

其他事件时间段数量

[in] astOtherEventTimes

其他事件回放时间段数组

[in] byRes

保留字段，当前转换或业务实现未使用
