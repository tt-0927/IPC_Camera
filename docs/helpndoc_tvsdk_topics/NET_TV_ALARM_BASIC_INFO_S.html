NET_TV_ALARM_BASIC_INFO_S

基础/常规报警 (0x1000 - 0x10FF)

struct
{
UINT32 dwAlarmType;
UINT32 dwAlarmInputNumber;
BYTE byAlarmOutputNumber[NET_TV_MAX_ALARM_OUT_NUM];
BYTE byAlarmRelateChannel[NET_TV_MAX_ALARM_IN_NUM];
BYTE byChannel[NET_TV_MAX_ALARM_IN_NUM];
BYTE byDiskNumber[NET_TV_LOCAL_DISK_MAX_NUM];
BYTE byPanoramaImg[NET_TV_PIC_DATA_MAX_LEN];
UINT32 dwPanoramaImgLen;
INT64 llTimestampMs;
BYTE byRes[128];
};

Parameters

[in] dwAlarmType

报警类型

[in] dwAlarmInputNumber

报警输入口

[in] byAlarmOutputNumber

触发的报警输出口，为1表示触发该口

[in] byAlarmRelateChannel

触发的录像通道，为1表示触发该通道

[in] byChannel

报警通道，为1表示触发该通道

[in] byDiskNumber

发生报警的硬盘，为1表示该硬盘异常

[in] byPanoramaImg

全景 JPEG 二进制图片

[in] dwPanoramaImgLen

全景 JPEG 图片长度

[in] llTimestampMs

报警时间戳，单位毫秒

[in] byRes

保留字段，当前转换或业务实现未使用

See Also

无。
