NET_TV_ALARM_STATISTICS_INFO_S

统计类通用告警，优先用于人流统计和人员密度统计

struct
{
UINT32 dwAlarmType;
UINT32 dwChannel;
UINT32 dwStatisticsType;
UINT32 dwRuleID;
INT64 llTimestampMs;
UINT32 dwReportSeq;
UINT32 dwEnterCount;
UINT32 dwLeaveCount;
UINT32 dwTotalCount;
UINT32 dwCurrentPeopleCount;
UINT32 dwAverageStayTimeSec;
UINT32 dwTargetCount;
NET_TV_ALARM_STATISTICS_TARGET_S stTargets[NET_TV_ALARM_STATISTICS_TARGET_MAX_NUM];
BYTE byPanoramaImg[NET_TV_PIC_DATA_MAX_LEN];
UINT32 dwPanoramaImgLen;
BYTE byRes[256];
};

Parameters

[in] dwAlarmType

报警类型/命令码

[in] dwChannel

通道号

[in] dwStatisticsType

统计子类型 NET_TV_STATISTICS_TYPE_E

[in] dwRuleID

规则 ID

[in] llTimestampMs

报告时间戳，单位毫秒

[in] dwReportSeq

统计报告序号

[in] dwEnterCount

累计进入人数

[in] dwLeaveCount

累计离开人数

[in] dwTotalCount

累计通行总人数

[in] dwCurrentPeopleCount

当前区域人数

[in] dwAverageStayTimeSec

平均停留时间，单位秒

[in] dwTargetCount

当前目标快照数量

[in] stTargets

目标快照列表

[in] byPanoramaImg

全景 JPEG 二进制图片

[in] dwPanoramaImgLen

全景 JPEG 图片长度

[in] byRes

保留字段，当前转换或业务实现未使用
