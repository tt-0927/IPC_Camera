NET_TV_OSD_CAP_S

通道OSD的能力集 OSD Capabilities (简化版，对应OsdConfig_S)

struct
{
BOOL bSupportOsd;
BOOL bSupportName;
BOOL bSupportTime;
BOOL bSupportWeek;
BOOL bSupportCustomColor;
UINT32 udwMaxOsdNum;
UINT32 udwSupportedFontSizeNum;
UINT32 audwSupportedFontSizeList[NET_TV_OSD_FONT_SIZE_TYPE_MAX_NUM];
UINT32 udwSupportedDateFormatNum;
UINT32 audwSupportedDateFormatList[NET_TV_OSD_DATE_FORMAT_MAX_NUM];
UINT32 udwSupportedTimeFormatNum;
UINT32 audwSupportedTimeFormatList[NET_TV_OSD_TIME_FORMAT_MAX_NUM];
UINT32 udwSupportedAlignNum;
UINT32 audwSupportedAlignList[8];
BYTE byRes[256];
};

Parameters

[in] bSupportOsd

是否支持OSD配置

[in] bSupportName

是否支持名称OSD

[in] bSupportTime

是否支持时间OSD

[in] bSupportWeek

是否支持星期显示

[in] bSupportCustomColor

是否支持自定义颜色

[in] udwMaxOsdNum

最大字符叠加数量

[in] udwSupportedFontSizeNum

支持的字体大小个数

[in] audwSupportedFontSizeList

支持的字体大小列表 NET_TV_OSD_FONT_SIZE_E

[in] udwSupportedDateFormatNum

支持的日期格式数量

[in] audwSupportedDateFormatList

支持的日期格式列表 NET_TV_OSD_DATE_FORMAT_E

[in] udwSupportedTimeFormatNum

支持的时间格式数量

[in] audwSupportedTimeFormatList

支持的时间格式列表 NET_TV_OSD_TIME_FORMAT_E

[in] udwSupportedAlignNum

支持的对齐方式数量

[in] audwSupportedAlignList

支持的对齐方式列表 NET_TV_OSD_ALIGN_E

[in] byRes

保留字段，当前转换或业务实现未使用

See Also

无。
