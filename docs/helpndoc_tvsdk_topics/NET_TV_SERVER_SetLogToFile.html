NET_TV_SERVER_SetLogToFile

设置SDK日志输出文件参数

BOOL NET_TV_SERVER_SetLogToFile(IN INT32 dwLogLevel, IN CHAR *strLogDir, IN INT32 dwLogFileSize, IN INT32 dwLogFileNum);

Parameters

[in] dwLogLevel

日志等级

[in] strLogDir

日志文件目录

[in] dwLogFileSize

单个日志文件大小

[in] dwLogFileNum

日志文件数量

Return Values

BOOL 类型返回值。TRUE 表示成功，FALSE 表示失败。接口返回失败时可调用 NET_TV_GetLastError 获取错误码。
