NET_TV_REPLAY_CTRL_INFO_S

回放控制信息

struct
{
INT32 dwChannel;
INT32 dwCtrlType;
FLOAT fSpeed;
INT32 nSeekTime;
INT32 nReplayType;
CHAR szSessionId[NET_TV_REPLAY_SESSION_ID_LEN];
CHAR szStartTime[NET_TV_LEN_64];
CHAR szEndTime[NET_TV_LEN_64];
CHAR szUrl[NET_TV_MAX_URL_LEN];
BYTE byRes[128];
};

Parameters

[in] dwChannel

通道号

[in] dwCtrlType

控制类型，参见 NET_TV_REPLAY_CTRL_CMD_E

[in] fSpeed

播放倍速

[in] nSeekTime

跳转播放时间，单位秒

[in] nReplayType

平台点播回放控制类型

[in] szSessionId

回放会话ID

[in] szStartTime

开始时间 "YYYY-MM-DD HH:MM:SS"

[in] szEndTime

结束时间 "YYYY-MM-DD HH:MM:SS"

[in] szUrl

当前回放播放地址

[in] byRes

保留字段，当前转换或业务实现未使用

See Also

无。
