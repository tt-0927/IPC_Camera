NET_TV_ALARM_EXCEPTION_INFO_S

设备异常/状态事件 (0x5000 - 0x50FF)

struct
{
UINT32 dwAlarmType;
UINT32 dwChannel;
UINT32 dwDiskNo;
UINT32 dwStatus;
BYTE byRes[256];
};

Parameters

[in] dwAlarmType

报警类型/命令码

[in] dwChannel

通道号(若无则填0)

[in] dwDiskNo

硬盘号(若无则填0)

[in] dwStatus

状态(0:恢复 1:触发)

[in] byRes

保留字段，当前转换或业务实现未使用

See Also

无。
