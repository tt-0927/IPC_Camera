NET_TV_GetReplayUrl

获取回放播放地址

BOOL NET_TV_GetReplayUrl(
IN LPVOID lpUserID,
INOUT LPNET_TV_REPLAY_URL_INFO_S pstInfo,
OUT INT32 *pdwBytesReturned
);

Parameters

[in] lpUserID

用户登录句柄

[in/out] pstInfo

回放查询条件和返回信息，调用前填通道/时间，返回后读取播放URL

[out] pdwBytesReturned

实际返回的数据长度指针，可为NULL

Return Values

TRUE表示成功,其他表示失败

Remarks

获取回放播放地址
