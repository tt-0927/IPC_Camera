NET_TV_SetLogToFile

设置日志

BOOL NET_TV_SetLogToFile(
IN INT32 dwLogLevel,
IN CHAR *strLogDir,
IN INT32 dwLogFileSize,
IN INT32 dwLogFileNum
);

Parameters

[in] dwLogLevel

日志的等级（默认为0）：0-表示关闭日志，1-表示只输出ERROR错误日志，2-输出ERROR错误信息和DEBUG调试信息，3-输出ERROR错误信息、DEBUG调试信息和INFO普通信息等所有信息

[in] strLogDir

日志路径

[in] dwLogFileSize

日志文件大小(单位：字节)

[in] dwLogFileNum

日志文件个数

Return Values

TRUE表示成功，FALSE/其他值表示失败
