NET_TV_GetDevConfig

获取设备的配置信息 Get configuration information of device

BOOL NET_TV_GetDevConfig(
IN LPVOID lpUserID,
IN INT32 dwChannelID,
IN INT32 dwCommand,
INOUT LPVOID lpOutBuffer,
OUT INT32 dwOutBufferSize,
OUT INT32 *pdwBytesReturned
);

Parameters

[in] lpUserID

用户登录句柄

[in] dwChannelID

通道号 Channel ID

[in] dwCommand

设备配置命令,参见# NET_TV_CONFIG_COMMAND_E

[in/out] lpOutBuffer

接收数据的缓冲指针

[out] dwOutBufferSize

接收数据的缓冲长度(以字节为单位),不能为0

[out] pdwBytesReturned

实际收到的数据长度指针,不能为NULL

Return Values

TRUE表示成功，FALSE/其他值表示失败

Remarks
