NET_TV_StartRecordFrameStream

启动录像帧TCP流

BOOL NET_TV_StartRecordFrameStream(
IN LPVOID lpUserID,
IN LPNET_TV_RECORD_FRAME_STREAM_COND_S pstCond,
OUT LPNET_TV_RECORD_FRAME_STREAM_INFO_S pstStreamInfo,
IN NET_TV_RecordFrameCallBack cbRecordFrame,
IN LPVOID lpUserData
);

Parameters

[in] lpUserID

用户登录句柄

[in] pstCond

录像帧流请求条件，包含通道、起止时间、媒体类型、TCP端口等

[out] pstStreamInfo

服务端返回的流信息，包含流ID、TCP端口、编码信息等

[in] cbRecordFrame

录像帧回调

[in] lpUserData

回调用户数据

Return Values

TRUE表示成功，FALSE表示失败，可调用NET_TV_GetLastError获取错误码

Remarks

启动录像帧TCP流
