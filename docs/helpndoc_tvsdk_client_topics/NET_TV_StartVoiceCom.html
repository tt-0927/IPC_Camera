NET_TV_StartVoiceCom

开始语音对讲

BOOL NET_TV_StartVoiceCom(
IN LPVOID lpUserID,
IN LPNET_TV_VOICECOM_START_INFO_S pstStartInfo,
IN NET_TV_VoiceComCallBack cbVoiceCom,
IN LPVOID lpUserData
);

Parameters

[in] lpUserID

用户登录句柄

[in] pstStartInfo

对讲启动参数, 包含设备端音频TCP端口和音频参数

[in] cbVoiceCom

音频数据回调

[in] lpUserData

回调用户数据

Return Values

TRUE 成功，FALSE 失败

Remarks

开始语音对讲
