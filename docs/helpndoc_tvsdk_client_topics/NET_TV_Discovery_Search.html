NET_TV_Discovery_Search

搜索局域网内设备（UDP 组播）

BOOL NET_TV_Discovery_Search(
IN const CHAR* szInterfaceIP,
IN UINT32 dwTimeoutMs,
OUT NET_TV_DISCOVERY_DEVICE_INFO_S* pDeviceList,
IN int nMaxCount,
OUT int* pnOutCount
);

Parameters

[in] szInterfaceIP

网卡 IP 地址，传 NULL 使用默认网卡

[in] dwTimeoutMs

等待响应超时 (ms)，建议 2000~5000

[out] pDeviceList

输出设备列表缓冲区

[in] nMaxCount

设备列表最大容量

[out] pnOutCount

实际发现的设备数量

Return Values

TRUE表示成功，FALSE表示失败，可调用NET_TV_GetLastError获取错误码

Remarks

重复调用 NET_TV_Discovery_Search 前无需调用 NET_TV_Init()
