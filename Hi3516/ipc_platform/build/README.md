# build

## 介绍
本部分主要介绍编译脚本所在的文件夹相关信息。

## 说明
1. **`image` 文件夹**：该文件夹存放的是打包固件脚本。
2. **`pack` 文件夹**：用于存放打包升级包脚本。
3. **`build.sh` 总编译脚本**：
    此脚本功能丰富，具体使用方式如下：
    - `./build.sh -a`：执行该命令可编译所有程序。
    - `./build.sh -m 程序名`：用于编译指定的单个程序，需将“程序名”替换为实际的程序名称。
    - `./build.sh -p`：执行该命令可编译升级包。
    - `./build.sh -i`：用于编译固件包，还可结合以下参数使用：
        - `-v 版本号`：通过此参数可指定版本号，将“版本号”替换为具体的版本数字。
    - `./build.sh -c`：运行此命令可清除所有临时文件。
    - `./build.sh -h`：执行该命令可获取帮助信息。
4. **`compile.sh` 文件**：自动摆渡编译所需脚本。
5. **`help.conf` 文件**：存放帮助说明相关内容。
6. **`log.conf` 文件**：脚本 `log` 函数的相关配置存放于此。
7. **`path.conf` 文件**：用于存放环境变量相关信息。
