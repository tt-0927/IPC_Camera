# ipc_platform

网络摄像机项目相关平台的构建仓库。  
包含程序编译、软件包构建、固件包构建、编译库、第三方工具等。

## 一、目录结构

### ipc_platform
项目的主要目录结构如下：

- **`build/`**  
  编译程序文件夹。编译脚本，打包脚本。

- **`environment/`**  
  包含构建固件包、软件包所需脚本、配置、板载项目文件，如板载启动脚本、配置文件。

- **`lib/`**  
  存放所有的第三方依赖库。

- **`tool/`**  
  项目中使用的辅助工具，例如调试工具 gdb、iperf等。

- **`ipc_platform.cmake`**  
  cmake编译工具链选项。
