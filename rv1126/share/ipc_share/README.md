# ipc_share

网络摄像机项目公共代码模块的仓库。  

## 一、目录结构

### ipc_platform
项目的主要目录结构如下：

- **`common/`**  
   公共定义

- **`control/`**  
   控制模块（事务）

- **`data_format/`**  
   数据格式模块

- **`data_structure/`**  
   数据结构模块

- **`design/`**  
   单例模式模板

- **`encrypt/`**  
   加密模块

- **`hardware/`**  
   硬件接口通用模块

- **`network/`**  
   网络模块

- **`protocols/`**  
   协议封装

- **`push_stream/`**  
   推流服务器

- **`ret/`**  
   公共返回码

- **`shared_library/`**  
   共享库

- **`standard/`**  
   标准的库封装接口，条件变量、锁、线程、条件变量的信号
