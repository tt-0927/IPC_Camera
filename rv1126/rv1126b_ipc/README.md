# RV1126B_IPC

瑞芯微RV1126平台网络摄像机项目。  

## 一、目录结构

### rv1106B_ipc
项目的主要目录结构如下：

- **`daemon/`**  
    守护进程
- **`file_management/`**  
    数据库进程
- **`include/`**  
    头文件定义
- **`main_app/`**  
    主进程
- **`operation_record/`**  
    运维升级
- **`record/`**  
    录制
- **`rtmp_client/`**  
    rtmp推流进程
- **`upgrade/`**  
    软件包升级
- **`CMakeLists.txt/`**  
    代码cmake配置文件
- **`ipc.cmake/`**  
    ipc编译cmake配置文件
